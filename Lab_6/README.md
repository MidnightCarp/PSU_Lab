# Задание 1  

ООП (вариант №1)  

### Текст задачи  

Разработать класс с одним строковым полем. Создать  конструктор  копирования.  Разработать метод, создающий строку  из первого и  последнего символов поля. Перегрузить метод ToString() для формирования строки из полей класса. Реализовать дочерний класс (его содержание предложить самостоятельно и описать в решении: какой содержательный смысл имеют поля; реализовать конструкторы; предложить и реализовать 2-3 метода). Протестировать все конструкторы и другие методы базового и дочернего классов.  

### Алгоритм решения  

=== Архитектура классов ===  

1. Базовый класс Movie (Фильм, содержит одно строковое поле)  
   A. Поле:  
         _title — название фильма  
   B. Конструкторы:  
        Movie(string title) — обычный конструктор, инициализирует название  
        Movie(Movie other) — конструктор копирования, создает копию существующего объекта  
   C. Методы:  
        GetTitle() — возвращает название фильма  
        GetFirstLastChars() — формирует строку из первого и последнего символов названия (так же обрабатывает пустую строку и строку из одного символа)  
        ToString() — переопределённый метод, возвращает строку с названием фильма  

3. Дочерний класс CharacteristicsFilm (Характеристика фильма)  
   A. Поля:  
        _isBasedOnBook (bool) — флаг, указывающий, снят ли фильм по книге  
        _genre (string) — жанр фильма  
        _rating (int) — оценка фильма по десятибалльной шкале  
   B. Конструкторы:  
       CharacteristicsFilm(...) — обычный конструктор, принимает название, флаг экранизации, жанр и оценку. Вызывает конструктор базового класса через :base(title)  
       CharacteristicsFilm(CharacteristicsFilm other) — конструктор копирования. Вызывает конструктор копирования базового класса через : base(other) и копирует поля дочернего класса  
   C. Методы:  
       GetBookStatus() — возвращает текстовый статус: «Да, фильм снят по книге» или «Нет, это оригинальный сценарий»  
       GetRatingCategory() — возвращает текстовую интерпретацию оценки: «Высокая» (8–10), «Средняя» (5–7), «Низкая» (1–4)  
       GetGenre() — возвращает жанр фильма  
       ToString() — перегруженный метод. Вызывает base.ToString() и добавляет информацию о жанре, экранизации и оценке  
 
=== Алгоритм работы ===   

1. Вспомогательные методы валидации ввода (реализованы три приватных метода для безопасного ввода данных)  
  A. GetValidString(prompt) — запрашивает строку, повторяет ввод, если строка пустая или состоит из пробелов  
  B. GetValidBool(prompt) — запрашивает логическое значение. Принимает «да/yes/y/1» как true, «нет/no/n/0» как false  
  C. GetValidInt(prompt, min, max) — запрашивает целое число в заданном диапазоне, повторяет ввод при ошибке  

2. Тестирование базового класса  
  A. Запрос у пользователя название фильма (GetValidString)  
  B. Создание объекта Movie с помощью обычного конструктора  
  C. Вызов методов GetFirstLastChars() и ToString()  
  D. Создание копии объекта с помощью конструктора копирования Movie(Movie other)  
  E. Вывод результата ToString() для копии (проверка корректности копирования)  

3. Тестирование дочернего класса  
  A. Запрос у пользователя: снят ли фильм по книге (GetValidBool), жанр (GetValidString), оценку (GetValidInt)  
  B. Создание объекта CharacteristicsFilm с помощью обычного конструктора  
  C. Вызов методов GetBookStatus(), GetRatingCategory() и ToString()  
  D. Создание копии объекта с помощью конструктора копирования CharacteristicsFilm(CharacteristicsFilm other)  
  E. Вывод результата ToString() для копии  

4. Завершение работы  
  Ожидание нажатия клавиши Enter (Console.ReadLine())

# Задание 2 и 3

Перегрузка операций (вариант №1)  

### Текст задачи  

В задании 2 необходимо реализовать определение класса (поля, свойства, конструкторы, перегрузка метода ToString() для вывода полей, заданный метод согласно варианту). Протестировать все методы, включая конструкторы.  
В задании 3 необходимо добавить к реализованному в задании 2 классу указанные в варианте перегруженные операции. Протестировать все методы.

### Алгоритм решения  

=== Архитектура классов ===   

Реализация класса Time   
1. Поля:    
  A. _hours (byte) — количество часов  
  B. _minutes (byte) — количество минут  

2. Конструктор: (Time(byte hours, byte minutes))  
  A. Принимает начальные значения часов и минут    
  B. Вычисляет общее количество минут: totalMinutes = hours * 60 + minutes  
  C. Вызывает приватный метод NormalizeTime(totalMinutes) для приведения времени к корректному формату (00:00 – 23:59)  

3. Методы:  
   1.NormalizeTime(int totalMinutes)  
   Вычисляет текущее общее количество минут   
   Прибавляет minutesToAdd (приведение к long для защиты от переполнения)  
   Берет остаток от деления на 1440 (минуты в сутках)    
   Создает и возвращает новый объект Time с полученными часами и минутами  
   2. Приватный метод SubtractMinutes(uint minutesToSubtract)  
   Вычисляет текущее общее количество минут   
   Вычитает minutesToSubtract (приведение к long)   
   Создает новый объект Time(0, 0) и вызывает для него NormalizeTime с отрицательным значением (метод сам обработает переход через полночь)   
   3. Переопределенный метод ToString()    
   Возвращает строку в формате ЧЧ:ММ (с ведущими нулями через :D2)  
   
4. Перегрузка операций  
   1.Унарные операции   
            ++ (инкремент): вызывает AddMinutes(1)  
            -- (декремент): вызывает SubtractMinutes(1)  
   2.Операции приведения типа  
            explicit operator byte: возвращает только часы (_hours), минуты отбрасываются  
            implicit operator bool: возвращает true, если часы или минуты не равны нулю, иначе false  
   3.Бинарные операции + (сложение)  
            Time + uint: вызывает t.AddMinutes(minutes)  
            uint + Time: вызывает t.AddMinutes(minutes) (операция коммутативна)  
   4.Бинарные операции - (вычитание)  
            Time - uint: вызывает t.SubtractMinutes(minutes)  
            uint - Time: создает объект Time(0, 0), добавляет к нему minutes минут, а затем вычитает из результата время t (uint трактуется как количество минут от начала суток). Возвращает новый объект Time   
 
=== Алгоритм работы ===   

1. Вспомогательные методы валидации ввода  
  A. GetValidByte(prompt, min, max): запрашивает число от min до max, повторяет ввод при ошибке  
  B. GetValidUInt(prompt): запрашивает неотрицательное целое число, повторяет ввод при ошибке  

2. Тестирование задания 2  
  A. Запрос: часы (0–23) и минуты (0–59)    
  B. Создание объекта Time  
  C. Вызов объекта через ToString()  
  D. Запросить количество минут для добавления  
  E. Вызвать AddMinutes и вывести результат  

3. Тестирование задания 3  
  A. Унарные операции: вызвать ++ и --, вывести результаты  
  B. Приведение к byte: явно привести объект к byte, вывести часы  
  C. Приведение к bool: неявно привести объект к bool, вывести результат  
  D. Бинарные операции +: запросить минуты, выполнить Time + uint и uint + Time, вывести оба результата   
  E. Бинарные операции -: запросить минуты, выполнить Time - uint и uint - Time, вывести оба результата  

4. Завершение работы  
  Ожидание нажатия клавиши Enter (Console.ReadLine())
