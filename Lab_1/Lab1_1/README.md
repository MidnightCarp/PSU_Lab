Задание 1
Генерация списков (вариант №1)
Текст задачи:
Создать список из двух чередующихся символов (символы вводятся с клавиатуры) 
Алгоритм решения:
   1. Реализация рекурсивной функции readSymbol
      1. Ввод символа с клавиатуры
      2. Проверка на char
      3. Повторный вызов функции, если проверка не пройдена
   
   2. Реализация рекурсивной функции readNumber
      1. Ввод числа с клавиатуры
      2. Проверка на int
      3. Повторный вызов функции, если проверка не пройдена
     
   3. Формирование списка для i от 1 до до 2*n включительно
      1. Если i чётное (i % 2 = 0), добавить в список char2
      2. Иначе (если i нечётное) добавить char1
      3. Вывести список на экран и завершить работу
