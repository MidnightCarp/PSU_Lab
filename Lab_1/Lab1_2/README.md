# Вахрушева Влада ИТС Лабораторная №1  
# Задание 2  
Рекурсия (вариант №1)  
### Текст задачи  
Найти сумму цифр натурального числа  
### Алгоритм решения  
1. Реализация рекурсивной функции readNumber  
   A. Ввод числа с клавиатуры  
   B. Проверка на int и на то, что число неотрицательное  
   C. Повторный вызов функции, если проверка не пройдена  

2. Реализация функции sumOfDigits  
   A. Передача числа num  
   B. Внутри объявляется вспомогательная рекурсивная функция sum с двумя параметрами: аккумулятор (acc) и число (x)  
   C. Если x = 0, вернуть acc (все цифры обработаны)  
   D. Иначе: прибавить к аккумулятору последнюю цифру числа (x % 10) и продолжить рекурсию с числом без последней цифры (x / 10)  
   E. Запустить sum с начальными параметрами: acc = 0, x = num  
   F. Вернуть результат  

3. Основная программа   
   A. Вызов readNumber для ввода числа (n)  
   B. Вызов sumOfDigits для получения суммы цифр числа n (result)  
   C. Вывод суммы на экран  
   D. Завершение работы
