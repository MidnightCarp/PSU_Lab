# Вахрушева Влада ИТС Лабораторная №1  
# Задание 3  
### Текст задачи  
Опишите функции, осуществляющие основные математические операции над комплексными числами (сложение, вычитание, умножение, деление, возведение в степень). Использовать готовый класс Complex запрещено.  
### Алгоритм решения  
1. Реализация рекурсивной функции readFloat  
   A. Ввод числа с клавиатуры  
   B. Проверка на double  
   C. Повторный вызов функции, если проверка не пройдена  
   
2. Реализация рекурсивной функции readInt  
   A. Ввод числа с клавиатуры  
   B. Проверка на int  
   C. Повторный вызов функции, если проверка не пройдена

3. Описание типа ComplexNumber  
   Объявление записи с двумя полями float: вещественная и мнимая часть комплексного числа  

4. Реализация базовых операций  
   A. Создание комплексного числа из двух переданных значений  
   B. Сложение: складываются отдельно действительная, отдельно мнимая части  
   C. Вычитание: вычитаются отдельно действительная, отдельно мнимая части  
   D. Умножение: по правилу (a+bi)(c+di) = (ac−bd) + (ad+bc)i  
   E. Деление: вычисление знаменателя d = c² + d², проверка на ноль, расчёт ((ac+bd)/d) + ((bc−ad)/d)i  

5. Реализация дополнительных операций  
   A. Модуль числа: sqrt(a² + b²)  
   B. Вычисление аргумента atan2(b, a)  
   C. Возведение в степень по формуле Муавра: если модуль = 0 вернуть 0 + 0i, иначе вычислить r = modulus z, θ = argument z, вернуть (rⁿ·cos(nθ)) + (rⁿ·sin(nθ))i  
   D. Сопряженность: замена мнимой части числа на противоположную  

6. Реализация функции вывода числа toString  
   A. Если мнимая часть = 0, вывести только действительную  
   B. Если действительная часть = 0, вывести только мнимую    
   C. Если мнимая часть положительная, вывести в формате a + bi  
   D. Если мнимая часть отрицательная, вывести в формате a − bi (с модулем мнимой части)

7. Основная программа  
   A. Вызов readFloat 4 раза для ввода действительной и мнимой части первого и второго числа (z1, z2)  
   B. Вызов readInt для ввода степени числа (n)  
   C. Создание комплексных чисел z1 и z2 через createComplex  
   D. Вывод результатов всех операций  
   E. Завершение работы (вернуть 0)
