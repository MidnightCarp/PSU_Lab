# Задание 1  
Seq.map  
### Текст задачи  
Решить задачу из лабораторной №2 (Задание 1. List.map) для последовательности  
> (вариант №1) Получить список из первых цифр чисел, содержащихся в исходном списке  
### Алгоритм решения   

1. Реализация рекурсивной функции readSequence  
   A. Ввод числа с клавиатуры   
   B. Если строка пустая — завершает генерацию последовательности  
   C. Если не пустая - проверка на Double  
   D. Если пройдена - добавляет число в последовательность (yield value), затем рекурсивно продолжает ввод оставшихся элементов (yield! readSequence)  
   E. Если не пройдена - выводит сообщение об ошибке, пропускает ввод и повторно вызывает функцию
   
2. Реализация функции firstDigit  
   A. Если число = 0, возращает 0  
   B. Иначе берет модуль числа, преобразовывает в строку, берет первый символ строки (Seq.head)  
   C. Обратное преобразование: символ в строку, строку в число  
   D. Возвращает полученную цифру  
   
3. Основная программа  
  A. Вызов readSequence для получения последовательности, сохранение в oldSequence, использование Seq.cache для запоминания введеных значений (во избежания лишнего повторения ввода)  
  B. Вывод исходной последовательности в виде списка (для полного вывода)  
  C. Формирование новой последовательности: применить к oldSequence функцию Seq.map int (отбросить дробную часть, получив целые числа), применить Seq.map firstDigit  
  D. Вывести полученную последовательность newSequence в виде списка (для полного вывода)  
  E. Завершение работы (вернуть 0)

# Задание 2  
Seq.fold  
### Текст задачи  
Решить задачу из лабораторной №2 (Задание 2. List.fold) для последовательности  
> (вариант №1) Сколько раз в списке встречается заданное число?    
### Алгоритм решения   

1. Реализация рекурсивной функции readStringSequence  
  A. Ввод строки с клавиатуры     
  B. Если строка пустая — завершает генерацию последовательности  
  C. Если не пустая - добавляет строку в последовательность (yield input), затем рекурсивно продолжает ввод оставшихся элементов (yield! readStringSequence)  
   
2. Реализация рекурсивной функции readNumber  
  A. Ввод числа с клавиатуры  
  B. Проверка на double  
  C. Повторный вызов функции, если проверка не пройдена  

3. Реализация функции countOccurrences для подсчёта вхождений  
  A. Принимает два параметра: искомую строку (target) и последовательность (items)  
  B. Проходится по последовательности с помощью Seq.fold, накапливая счётчик: если элемент последовательности = target, счетчик увеличивается на 1  
  C. Возвращает итоговое значение счетчика  
   
4. Основная программа  
  A. Вызов readStringSequence для получения последовательности, сохранение в items, использование Seq.cache для запоминания введеных значений (во избежания лишнего повторения ввода)  
  B. Вывод исходной последовательности в виде списка (для полного вывода)  
  C. Вызов readNumber для получения искомого числа, сохранение результата в comparisonValue  
  D. Преобразование числа в строку для сравнения с элементами последовательности  
  E. Вызов countOccurrences, вывод полученного результата на экран  
  F. Завершение работы (вернуть 0)

# Задание 3  
Решить с использованием последовательности задачу на обработку файлов/каталогов (вариант №1)  
### Текст задачи  
Вывести путь ко всем текстовым файлам (*.txt) в указанном каталоге и его подкаталогах.  
### Алгоритм решения   

1. Реализация рекурсивной функции allTextFiles  
   A. Принимает на вход путь к каталогу  
   B. Создает последовательность  
   C. Находит все файлы с расширением (*.txt) через Directory.EnumerateFiles с параметром SearchOption.TopDirectoryOnly
   D. Рекурсивно спускается в каждый подкаталог и добавляет пути в текущую последовательность (yield!) 
   
2. Реализация рекурсивной функции readDirectoryPath  
   A. Считывает строку с клавиатуры, убирает лишние пробелы по краям (Trim)  
   B. Проверяет существование введенного каталога. Если не существует, выводит сообщение и рекурсивно повторяет ввод  
   C. Если существует - возвращает введенный путь  

3. Реализация функции печати последовательности printSequence  
   A. Проверяет, пуста ли последовательность  
   B. Если пуста - выводит сообщение, что файлов нет  
   C. Иначе проходит по всем элементам через Seq.iter и выводит каждый на отдельной строке  
   
4. Основная программа  
  A. Вызов readDirectoryPath для получения пути к каталогу, сохранение результата в rootDir  
  B. Вывод allTextFiles с rootDir для поиска файлов, сохранение результата в result  
  C. Вызов printSequence для вывода найденных путей  
  D. Завершение работы (вернуть 0)
