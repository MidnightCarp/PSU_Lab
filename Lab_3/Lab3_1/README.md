# Вахрушева Влада ИТС Лабораторная №3  
# Задание 1  
Seq.map  
### Текст задачи  
Решить задачу из лабораторной №2 (Задание 1. List.map) для последовательности  
> (вариант №1) Получить список из первых цифр чисел, содержащихся в исходном списке  
### Алгоритм решения   

1. Вызов рекурсивной функции readSequence  
   A. Ввод числа с клавиатуры   
   B. Если строка пустая — завершить генерацию последовательности  
   C. Если не пустая - проверка на Double  
   D. Если пройдена - добавляет число в последовательность (yield value) и повторно вызывает функцию  
   E. Если не пройдена - выводит сообщение и повторно вызывает функцию  
   F. Рекурсивно продолжить ввод (yield! readSequence), добавив оставшиеся элементы в конец последовательности  
   
2. Реализация функции firstDigit  
   A. Если число = 0, возращает 0  
   B. Иначе берет модуль числа, преобразовывает в строку, берет первый символ строки (Seq.head)  
   C. Обратное преобразование: символ в строку, строку в число  
   D. Возвращает полученную цифру  
   
3. Основная программа  
  A. Вызов readSequence, преобразование последовательности в список, сохранение в oldSequence  
  B. Вывод исходной последовательности на экран в стандартном формате  
  C. Формирование новой последовательности: применить к oldSequence функцию List.map int (отбросить дробную часть, получив целые числа), применить к List.map firstDigit  
  D. Вывести полученную последовательность newSequence на экран в стандартном формате  
  E. Завершение работы (вернуть 0)
