# Вахрушева Влада ИТС Лабораторная №3  
# Задание 1  
Seq.map  
### Текст задачи  
Решить задачу из лабораторной №2 (Задание 1. List.map) для последовательности  
> (вариант №1) Получить список из первых цифр чисел, содержащихся в исходном списке  
### Алгоритм решения   

1. Реализация рекурсивной функции readSequence  
   A. Ввод числа с клавиатуры   
   B. Если строка пустая — завершает генерацию последовательности  
   C. Если не пустая - проверка на Double  
   D. Если пройдена - добавляет число в последовательность (yield value), затем рекурсивно продолжает ввод оставшихся элементов (yield! readSequence)  
   E. Если не пройдена - выводит сообщение об ошибке, пропускает ввод и повторно вызывает функцию
   
2. Реализация функции firstDigit  
   A. Если число = 0, возращает 0  
   B. Иначе берет модуль числа, преобразовывает в строку, берет первый символ строки (Seq.head)  
   C. Обратное преобразование: символ в строку, строку в число  
   D. Возвращает полученную цифру  
   
3. Основная программа  
  A. Вызов readSequence для получения последовательности, сохранение в oldSequence, использование Seq.cache для запоминания введеных значений (во избежания лишнего повторения ввода)  
  B. Вывод исходной последовательности в виде списка (для полного вывода)  
  C. Формирование новой последовательности: применить к oldSequence функцию Seq.map int (отбросить дробную часть, получив целые числа), применить Seq.map firstDigit  
  D. Вывести полученную последовательность newSequence в виде списка (для полного вывода)  
  E. Завершение работы (вернуть 0)
