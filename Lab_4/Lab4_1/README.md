# Вахрушева Влада ИТС Лабораторная №4  
# Задание 1  
Решить задачу на построение нового дерева по заданному (map) (вариант №1)  
### Текст задачи  
Дерево содержит строки. Добавить к каждой строке заданный символ в конец.    
### Алгоритм решения   

1. Описание типа BinaryTree    
   Объявляет обобщенный тип с двумя случаями: пустое дерево и узел, содержащий значение, левое и правое поддерево  
   
2. Реализация функции печати дерева printTree    
   A. Объявляет внутри вспомогательную рекурсивную функцию printNode с параметрами: depth (глубина), prefix (префикс для отступов), isLeft (левый ли это потомок), node (текущий узел)  
   B. Если узел пуст (Empty) — ничего не делает  
   C. Если узел содержит значение: определяет символ ветки (если глубина > 0, то "├─ " для левого или "└─ " для правого, иначе пустая строка)  
   D. Выводит строку: префикс, ветка, значение  
   E. Вычисляет префикс для потомков: если глубина = 0, то пусто, иначе добавить "│ " (если левый) или " " (если правый)  
   F. Рекурсивно повторяет вызов для левого и правого поддерева с увеличенной глубиной  
   G. Запускает printTree с начальными параметрами  

3. Реализация рекурсивной функции buildTree  
   A. Принимает параметры: random (случайное значение), depth (текущая глубина), maxDepth (максимальная глубина)  
   B. Если depth >= maxDepth — вернуть Empty (достигли максимальной глубины)  
   C. Иначе генерирует случайное число, преобразовывает его в строку, рекурсивно строит правое и левое поддерево, увеличивая глубину  
   D. Возвращает узел  

4. Реализация рекурсивной функции mapTree  
   A. Принимает параметры: f (функция преобразования) и tree (дерево).  
   B. Если дерево пустое — вернуть Empty  
   C. Если дерево содержит узел: применяет f к значению узла, рекурсивно применяет mapTree к левому и правому поддереву, возвращает новый узел с преобразованным значением  

5. Реализация рекурсивной функции readSymbol  
   A. Ввод символа с клавиатуры  
   B. Проверка на char  
   C. Повторный вызов функции, если проверка не пройдена  
   
6. Основная программа  
  A. Создает генератор случайных чисел  
  B. Задается максимальная глубина дерева  
  C. Вызов buildTree для построения дерева tree 
  D. Вывов printTree для вывода исходного дерева  
  E. Вызов readSymbol для ввода добавляемого символа  
  F. Применение mapTree для добавления символа к каждой строки дерева  
  G. Вывов printTree для вывода нового дерева  
  H. Завершение работы (вернуть 0)
