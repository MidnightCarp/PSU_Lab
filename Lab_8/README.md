Разработать консольное приложение (вариант №1)

### Текст задачи

Каталог фильмов

### Алгоритм решения

Вот описание алгоритма программы, составленное по вашему коду и заданию. Программа представляет собой консольное приложение с меню для управления базой данных фильмов, которая хранится в бинарном файле.

---

### Архитектура программы

Программа разделена на три логические части (класса):

1.  **`Movie.cs` (Модель данных):** Описывает структуру одного фильма. Содержит свойства (`Id`, `Title`, `Genre`, `Year`, `Rating`, `DurationMinutes`), два конструктора (пустой для десериализации и с параметрами) и переопределенный метод `ToString()` для вывода информации.
2.  **`MovieDatabase.cs` (Сервис/Бизнес-логика):** Вспомогательный класс, который управляет коллекцией фильмов (`List<Movie>`). Отвечает за загрузку/сохранение в бинарный файл (`movies.dat`), добавление, удаление, просмотр и выполнение 4 LINQ-запросов.
3.  **`Program.cs` (Интерфейс):** Точка входа. Отвечает за взаимодействие с пользователем: вывод меню, считывание ввода, валидацию данных и вызов соответствующих методов `MovieDatabase`.

---

### Алгоритм работы программы

1. Инициализация (в Main)
1. Задать путь к бинарному файлу: movies.dat.
2. Создать экземпляр класса MovieDatabase, передав ему путь к файлу.
3. В конструкторе MovieDatabase автоматически вызывается метод LoadFromFile():
   * Проверить существование файла. Если его нет — вернуться (база пуста).
   * Открыть файл через BinaryReader.
   * Считать количество записей (count).
   * В цикле от 0 до count считать поля каждого фильма (Id, Title, Genre, Year, Rating, DurationMinutes) и добавить объект Movie в список _movies.
   * Обработать исключения IOException и UnauthorizedAccessException.

2. Главное меню (Цикл while(true) в Main)
1. Очистить консоль и вывести список пунктов меню (от 0 до 7).
2. Считать выбор пользователя (choice).
3. В блоке try-catch обработать выбор через switch:
   * **"1" (Просмотр):** Вызвать database.ShowAll().
     * Если список пуст — вывести сообщение. Иначе — пройти по всем фильмам и вывести ToString().
   * **"2" (Добавление):** Вызвать AddMovieFromConsole(database).
     * Запросить ID, название, жанр, год, рейтинг (0-10), длительность.
     * Создать объект Movie и вызвать database.AddMovie(movie).
     * В AddMovie: проверить, нет ли фильма с таким ID. Если нет — добавить в список, вызвать SaveToFile() и вывести сообщение.
   * **"3" (Удаление):** Запросить ID и вызвать database.DeleteMovie(id).
     * Найти фильм по ID через LINQ (FirstOrDefault). Если найден — удалить, вызвать SaveToFile(). Иначе — сообщить, что не найден.
   * **"4" (Запрос A):** Запросить жанр и минимальный рейтинг. Вызвать database.QueryByGenreAndRating(genre, minRating).
     * **LINQ-запрос (возвращает перечень):** Where (жанр совпадает + рейтинг > minRating) -> ToList().
   * **"5" (Запрос B):** Запросить год. Вызвать database.QueryByYearSorted(year).
     * **LINQ-запрос (возвращает перечень):** Where (год > заданного) -> OrderByDescending (по рейтингу) -> ToList().
   * **"6" (Запрос C):** Вызвать database.QueryAverageRating().
     * **LINQ-запрос (возвращает одно значение):** Average(m => m.Rating).
   * **"7" (Запрос D):** Вызвать database.QueryTopRatedMovie().
     * **LINQ-запрос (возвращает одно значение):** OrderByDescending(m => m.Rating).FirstOrDefault().
   * **"0":** Выйти из программы (return).
   * **По умолчанию:** Вывести сообщение о неверном пункте.
4. Если во время выполнения возникла ошибка — перехватить её в catch (Exception ex) и вывести сообщение.
5. Вывести «Нажмите любую клавишу для продолжения...» и вызвать Console.ReadKey().

3. Методы валидации ввода (в Program)
Для защиты от некорректного ввода используются три метода:
*   GetValidInt: Запрашивает положительное целое число, повторяет ввод при ошибке.
*   GetValidDouble: Запрашивает число в заданном диапазоне (min–max), повторяет ввод при ошибке.
*   GetValidString: Запрашивает непустую строку, удаляет лишние пробелы, повторяет ввод при ошибке.

4. Сохранение изменений (в MovieDatabase)
*   Метод SaveToFile() вызывается **только** после операций добавления (AddMovie) и удаления (DeleteMovie).
*   Он открывает файл через BinaryWriter, записывает количество фильмов и все поля каждого фильма в том же порядке, в котором они считывались.
