# Вахрушева Влада ИТС Лабораторная №7  

# Задание  

Текстовые файлы (вариант №1)  

### Текст задачи  

Выполнить все задания в одном проекте, решение всех задач оформить в виде двух классов со статическими методами, решающими поставленные задачи.   
1) Количество элементов файла чётно. Определить разность суммы элементов первой и второй половины файла.  
2) Вычислить сумму элементов.  
3) Переписать в другой текстовый файл самую короткую и самую длинную строки.   
4) Получить в новом файле те компоненты исходного файла, которые являются четными.  
5) Информация о багаже пассажира описывается массивом, где каждый элемент содержит название единицы  багажа  (чемодан,  сумка,  коробка  и  т.д.)  и  ее  массу. Дан файл, содержащий сведения о багаже нескольких пассажиров. Найти багаж, средняя масса одной единицы багажа, в котором отличается не более чем на m кг от общей средней массы одной единицы багажа.  
6) Составить программу, которая удаляет из списка L все элементы E, если такие есть.  
7) Напечатать в обратном порядке элементы непустого списка L.  
8) В городе имеется n общеобразовательных учебных заведений, которые могут закупать компьютерную технику и оргтехнику. Есть перечень компьютерных фирм, где может производится закупка. Ответить на следующие вопросы: 1) в каких фирмах закупка производилась каждым из заведений? 2) в каких фирмах закупка производилась хотя бы одним из заведений? 3) в каких фирмах ни одно из заведений не закупало мониторы?  
9) Файл содержит текст на русском языке. Напечать в алфавитном порядке все звонкие согласные буквы, которые входят хотя бы в одно слово.  
10) На вход программы подаются фамилии и имена участников. Известно, что общее количество участников не превосходит 100. В первой строке вводится количество участников, принимающих участие в соревнованиях. Далее следует N строк, имеющих формат <...>. Требуется написать программу, которая формирует и печатает уникальный логин для каждого участника по следующему правилу: если фамилия встречается первый раз, то логин - это фамилия, в конец которой приписывается число 2 и т.д.  

### Алгоритм решения  

Задание 1. Разность сумм половин файла
1. Проверить существование файла task1.txt. Если его нет — сгенерировать его: создать четное количество строк (от 5 до 10, умноженное на 2), каждая строка содержит случайное число от 1 до 100.
2. Считать все строки файла.
3. Преобразовать строки в массив целых чисел (int[]).
4. Найти середину массива (half = длина / 2).
5. Вычислить сумму первой половины (sum1) и второй половины (sum2).
6. Вывести разность: sum1 - sum2.

Задание 2. Сумма элементов файла
1. Проверить существование task2.txt. Если нет — сгенерировать: создать 4 строки, в каждой от 2 до 5 случайных чисел (1–50), разделенных пробелами.
2. Считать весь текст файла.
3. Разбить текст на части, используя пробелы, переносы строк и табы как разделители.
4. Преобразовать каждую часть в int и просуммировать.
5. Вывести общую сумму.

Задание 3. Короткая и длинная строка
1. Проверить существование task3.txt. Если нет — создать файл с заданным набором строк.
2. Считать все строки.
3. Инициализировать shortest и longest первой строкой.
4. Пройти по всем строкам: если текущая строка короче shortest — обновить shortest; если длиннее longest — обновить longest.
5. Записать найденные строки в новый файл task3_out.txt.

Задание 4. Четные компоненты бинарного файла
1. Проверить существование task4.bin. Если нет — сгенерировать: записать 10 случайных чисел (1–100) в бинарном формате.
2. Открыть файл для чтения (BinaryReader).
3. Считывать числа по одному (ReadInt32), пока не достигнут конец файла.
4. Если число четное (num % 2 == 0), добавить его в список evenNumbers.
5. Открыть новый файл task4_out.bin для записи (BinaryWriter).
6. Записать все четные числа в новый файл.

Задание 5. Багаж (XML)
1. Проверить существование task5.xml. Если нет — создать список объектов Luggage (Чемодан, Сумка, Коробка и т.д.) и сериализовать его в XML.
2. Десериализовать XML обратно в List<Luggage>.
3. Вычислить общую сумму весов и средний вес (avgWeight).
4. Запросить у пользователя допустимое отклонение m.
5. Пройти по всем элементам: если Math.Abs(item.Weight - avgWeight) <= m, вывести название и вес этого багажа.

Задание 6. Удаление элементов из List
1. Создать список L с тестовыми данными.
2. Запросить у пользователя элемент E для удаления.
3. Пройти по списку в **обратном порядке** (от последнего индекса к нулю). Если элемент равен E, удалить его через RemoveAt(i).
4. Вывести измененный список.

Задание 7. Обратный порядок LinkedList
1. Создать LinkedList<int> и заполнить его элементами (10, 20, 30, 40).
2. Получить последний узел (L.Last).
3. Пока текущий узел не равен null: вывести его значение и перейти к предыдущему узлу (current.Previous).

Задание 8. Закупки (HashSet, Dictionary)
1. Создать множества: institutions (учебные заведения), allFirms (все фирмы).
2. Создать словарь purchases, где ключ — заведение, значение — множество фирм, где оно закупалось.
3. **Вопрос 1:** Вывести содержимое словаря (каждое заведение и его фирмы).
4. **Вопрос 2:** Создать множество firmsWithPurchases. Пройти по всем значениям словаря и добавить фирмы в это множество. Вывести результат.
5. **Вопрос 3:** Создать множество firmsWithoutPurchases. Пройти по allFirms: если фирмы нет в firmsWithPurchases, добавить её в новое множество. Вывести результат.

Задание 9. Звонкие согласные (HashSet)
1. Проверить существование task9.txt. Если нет — создать файл с русским текстом.
2. Считать текст, привести к нижнему регистру.
3. Разбить текст на слова, используя знаки препинания и пробелы как разделители.
4. Задать строку звонких согласных: "бвгджзлмнр".
5. Создать HashSet<char>. Пройти по всем словам и символам: если символ есть в строке звонких согласных, добавить его в множество (это автоматически убирает дубликаты).
6. Преобразовать множество в список, отсортировать его.
7. Вывести отсортированный список букв.

Задание 10. Логины (Dictionary)
1. Проверить существование task10.txt. Если нет — создать файл с ФИО (например, "Иванова Мария", "Петров Сергей" и т.д.).
2. Считать все строки.
3. Создать Dictionary<string, int> для подсчета вхождений фамилий.
4. Для каждой строки:
   * Разделить строку по пробелу, взять фамилию (первый элемент).
   * Если фамилия уже есть в словаре: увеличить счетчик и вывести "Фамилия + Счетчик" (например, "Петров2").
   * Если фамилии нет: добавить её в словарь со значением 1 и вывести просто "Фамилию".
