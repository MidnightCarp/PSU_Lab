# Задание 1  

Рекурсия (вариант №1)  

### Текст задачи  

Дано натуральное число N. Составить программу формирования списка, элементами которого являются цифры числа N.  

### Алгоритм решения  

1. Предикат digits/2 рекурсивно формирует список цифр натурального числа N

2. Базовый случай: число из одной цифры.  
   A. Проверка: N >= 0 (число неотрицательное), N < 10 (число является одной цифрой)  
   B. Вернуть список [N]  

3. Рекурсивный случай: более одной цифры  
   A. Проверка: N >= 10 (в числе больше одной цифры)  
   B. Отбросить последнюю цифру (N1 is N // 10)  
   C. Выделить последнюю цифру (D  is N mod 10)  
   D. Рекурсивно получить оставшиеся цифры  
   E. Дописать последнюю цифру: объединить список L1 с одноэлементным списком [D] (append записывает элемент в конец списка). Результат объединения — итоговый список L

# Задание 2  

Списки (вариант №1)  

### Текст задачи  

Определить, сколько раз встречается минимальный элемент в списке.    

### Алгоритм решения  

1. Предикат min_list/2 (поиск минимума списка)  
   A. Базовый случай: если список состоит из одного элемента [X] — минимум равен X  
   B. Рекурсивный случай: если список имеет вид [H|T] (голова и хвост). Рекурсивно находится минимум хвоста (TailMin), затем сравнивается с головой.  
   C. Если H < TailMin — минимум равен H, иначе — минимум равен TailMin  
   D. Передать результат через переменную Min  

2. Предикат count_occurrences/3 (подсчёт вхождений элемента)  
   A. Базовый случай: если список пуст — счётчик равен 0  
   B. Рекурсивный случай: если список имеет вид [H|T]. Рекурсивно подсчитать вхождения в хвосте, сравниваем голову с искомым элементом (E)  
   C. Если H =:= E — увеличение счётчика. Иначе - оставить счетчик прежним  
   D. Передать результат через переменную Count  

3. Предикат min_count/2 (основной)  
   A. Найти минимальный элемент списка: min_list(List, Min)  
   B. Подсчитать, сколько раз этот минимум встречается в исходном списке: count_occurrences(List, Min, Count)  
   C. Передать количество вхождений через переменную Count

# Задание 3  

Решить задачу на обработку списка (вариант №1)  

### Текст задачи  

Определим множество как список без повторяющихся элементов. Найти симметричную разность множеств.  

### Алгоритм решения  

1. Предикат member_/2 (проверка принадлежности элемента множеству)
   A. Базовый случай: если голова списка равна искомому элементу X — элемент принадлежит множеству
   B. Рекурсивный случай: если голова не равна X, рекурсивно проверить хвост списка

2. Предикат difference/3 (разность множеств: A \ B)   
   A. Базовый случай: если первый список пуст — результат тоже пуст    
   B. Рекурсивный случай: если первый список имеет вид [H|T] - проверить, принадлежит ли голова H множеству B (вызов member_)  
   C. Если H принадлежит B — пропустить его и рекурсивно обработать хвост  
   D. Если H не принадлежит B — добавить его в начало результата и рекурсивно обработать хвост  

3. Предикат union/3 (объединение множеств: A ∪ B)   
   A. Базовый случай: если первый список пуст — результатом является второй список B  
   B. Рекурсивный случай: если первый список имеет вид [H|T] - проверить, принадлежит ли голова H множеству B  
   C. Если H принадлежит B — пропустить его (избегание дублирования) и рекурсивно обработать хвост    
   D. Если H не принадлежит B — добавить его в начало результата и рекурсивно обработать хвост    

4. Предикат symmetric_difference/3 (симметричная разность: A △ B)  
   A. Вычислить разность первого множества и второго: вызов difference(A, B, AminusB)  
   B. Вычислить разность второго множества и первого: вызов difference(B, A, BminusA)  
   C. Объединить полученные результаты: union(AminusB, BminusA, Result)  
   D. Передать итоговое множество Result

# Задание 4  

Решить логическую задачу (вариант №1)  

### Текст задачи  

Болельщики  футбольных  команд  делали  прогнозы  об  итогах  соревнований "Турнир четырех":  
— Я уверен, что Спартак будет чемпионом, а ЦСКА займет последнее место — сказал Иван.  
— Что  ты,  Спартак  выше  третьего  не  поднимется,  а  ЦСКА  станет  вторым  — возразил Сергей.  
— Чемпионом  будет  Динамо,  а  ЦСКА  войдет  в  тройку  сильнейших  —  сделал свой прогноз Петр.   
— Динамо  будет  вторым,  а  вот  Ротор  точно  будет  последним  —  промолвил Алексей.  
Выяснилось, что каждый из болельщиков был прав в одном прогнозе и ошибся во втором. Как распределились места, занятые командами?   

### Алгоритм решения  

1. Предикат solve/1 (основной)  
   Генерация всех возможных распределений мест через permutation([1, 2, 3, 4], [S, C, D, R]) (перебор всех перестановок)  

2. Проверка условий для каждого болельщика     
   A. Для каждого прогноза вводится переменная-флаг, которая принимает значение 1, если прогноз сбылся, и 0, если нет   
   B. Записывается каждое условие по отдельности. В флаг ставится 1, если оно правдиво, и 0, если нет  
   C. Проводится проверка (V1 + V2 =:= 1), потому что только один прогноз верен  

3. Формирование результата     
   A. Если все 4 проверки пройдены успешно (все суммы равны 1), значит найдено верное распределение мест   
   B. Передать список структур (команда и место) в Result  

4. Механизм бэктрекинга (перебора)    
   A. Если хотя бы одна проверка не прошла (V1 + V2 =\= 1), Prolog отменяет текущее присвоение переменных     
   B. Возвращение к шагу 1, который генерирует следующую перестановку    
   C. Повторение, пока не найдена комбинация, удовлетворяющая условиям
