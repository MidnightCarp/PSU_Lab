# Задание 1  

Рекурсия (вариант №1)  

### Текст задачи  

Дано натуральное число N. Составить программу формирования списка, элементами которого являются цифры числа N.  

### Алгоритм решения  

**1: Инициализация**
1. Запускается предикат `main`.
2. `main` вызывает предикат `loop_digits`.

**2: Начало цикла**
1. Активируется предикат `repeat`, который создает точку возврата для организации бесконечного цикла.

**3: Запрос ввода**
1. На экран выводится приглашение для ввода чисел.
2. Буфер вывода очищается (`flush_output`), чтобы текст появился сразу.
3. Считывается строка ввода от пользователя и сохраняется в переменную `S`.

**4: Проверка на выход**
1. Проверяется, равна ли строка `S` символу `"q"`.
2. **Если да (Пользователь хочет выйти):**
   * Выводится сообщение `Exiting program.`
   * `!` отсекает точку возврата, созданную `repeat`. Цикл прерывается.
   * Программа завершается.
3. **Если нет:** Переход к 5 шагу.

**5: Преобразование в число**
1. Программа пытается преобразовать строку `S` в число `N` (`number_string`).
2. Проверяется, является ли `N` целым числом (`integer`) и больше или равно нулю (`N >= 0`).
3. **Если это натуральное число:**
   * Число `N` преобразуется в список ASCII-кодов его символов (`number_codes`).
   * С помощью `maplist` каждый код преобразуется в числовое значение цифры с помощью предиката `code_digit`.
   * На экран выводится полученный список цифр: `List of digits: [1, 2, 3]`.
4. **Если это не натуральное число:**
   * Выводится сообщение об ошибке.

**6: Возврат к началу**
1. Вызывается предикат `fail`. Это заставляет программу "откатиться" назад.
2. Так как `fail` всегда ложен, управление возвращается к ближайшей точке возврата — предикату `repeat`.
3. Цикл начинается заново (переход к 3 шагу).

**Реализация предиката `code_digit`**
Предикат используется для перевода ASCII-кода символа в его числовое значение.
* `Code` — это ASCII-код символа.
* `0'0` — это синтаксис Prolog для обозначения ASCII-кода символа `'0'`.
* `Digit is Code - 0'0` — вычитает 48 из кода. Это позволяет получить реальное число из символа.

# Задание 2  

Списки (вариант №1)  

### Текст задачи  

Определить, сколько раз встречается минимальный элемент в списке.    

### Алгоритм решения  

**1: Инициализация**
1. Запускается предикат `main`.
2. `main` вызывает `loop_count_min`.

**2: Начало цикла**
1. Активируется предикат `repeat`, который создает точку возврата для бесконечного цикла.

**3: Запрос ввода**
1. На экран выводится приглашение для пользователя.
2. Буфер вывода очищается (`flush_output`), чтобы текст появился сразу.
3. Считывается терм от пользователя с помощью `read(Input)`. 

**4: Проверка на выход**
1. Проверяется, равен ли введенный терм `Input` атому `'q'`.
2. **Если да (Пользователь хочет выйти):**
   * Выводится сообщение.
   * `!` (cut) отсекает точку возврата, созданную `repeat`. Цикл прерывается.
   * Программа завершается.
3. **Если нет:** Переход к 5 шагу.

**5: Проверка корректности ввода**
1. Проверяется, является ли `Input` списком (`is_list(Input)`) и не является ли он пустым (`Input \= []`).
2. **Если это корректный непустой список:**
   * Вызывается `min_list(Input, Min)` для поиска минимального элемента.
   * Вызывается `count_occurrences(Input, Min, Count)` для подсчета количества вхождений `Min` в список.
   * На экран выводится результат: `Minimum element ~w occurs ~w times.`
3. **Если это не список или список пуст:**
   * Выводится сообщение об ошибке: `Error: enter a non-empty list or q.`

**6: Возврат к началу**
1. Вызывается предикат `fail`. Это заставляет программу "откатиться" назад.
2. Так как `fail` всегда ложен, управление возвращается к ближайшей точке возврата — предикату `repeat`.
3. Цикл начинается заново (переход к 3 шагу).

**Реализация предиката `count_occurrences/3`**
Этот предикат рекурсивно подсчитывает, сколько раз элемент `E` встречается в списке.
*   **Базовый случай:** Если список пуст (`[]`), количество равно `0`.
*   **Случай 1 (Совпадение):** Если голова списка (`H`) равна искомому элементу (`H =:= E`), то счетчик увеличивается на 1 (`C is C1 + 1`), и проверка продолжается для хвоста списка (`T`). Символ `!` (cut) здесь предотвращает ненужный переход к третьему правилу.
*   **Случай 2 (Несовпадение):** Если голова списка не равна элементу, счетчик не меняется, и проверка продолжается для хвоста списка.

# Задание 3  

Решить задачу на обработку списка (вариант №1)  

### Текст задачи  

Определим множество как список без повторяющихся элементов. Найти симметричную разность множеств.  

### Алгоритм решения  

**1: Инициализация**
1. Запускается предикат `main`.
2. `main` вызывает `loop_symdiff`.

**2: Запрос первого множества**
1. На экран выводится приглашение на ввод для пользователя.
2. Считывается терм от пользователя с помощью `read(A)`.

**3: Проверка на выход (для первого множества)**
1. Проверяется, равен ли введенный терм `A` атому `q`.
2. **Если да:** Выводится сообщение `Exit.`, и программа завершается (нет рекурсивного вызова).
3. **Если нет:** Переход к 4 шагу.

**4: Запрос второго множества**
1. На экран выводится приглашение на ввод для пользователя.
2. Считывается терм от пользователя с помощью `read(B)`.

**5: Проверка на выход (для второго множества)**
1. Проверяется, равен ли `B` атому `'q'` или `'Q'`.
2. **Если да:** Выводится сообщение `Exit.`, и программа завершается.
3. **Если нет:** Переход к 6 шагу.

**6: Вычисление симметрической разности**
1. Вызывается `difference(A, B, D1)`. Находит все элементы, которые есть в `A`, но отсутствуют в `B`.
2. Вызывается `difference(B, A, D2)`. Находит все элементы, которые есть в `B`, но отсутствуют в `A`.
3. Вызывается `append(D1, D2, SymDiff)`. Объединяет два полученных списка в один — это и есть симметрическая разность.

**7: Вывод результата**
1. На экран выводится результат.

**8: Повтор цикла**
1. Вызывается `loop_symdiff` снова (рекурсивный вызов).
2. Программа возвращается ко 2 шагу (запрос первого множества).

**Реализация вспомогательного предиката `difference/3`**
Этот предикат реализует операцию разности множеств. Он работает рекурсивно:
*   **Базовый случай:** `difference([], _, [])`. Если первый список пуст, результат тоже пуст.
*   **Случай 1 (Элемент не входит во второй список):** 
   Если голова первого списка (`H`) не принадлежит второму списку, то она включается в результат, и рекурсия продолжается для хвоста (`T`).
*   **Случай 2 (Элемент входит во второй список):**
   Если голова первого списка принадлежит второму списку, она просто игнорируется (не попадает в результат), и рекурсия продолжается для хвоста.

# Задание 4  

Решить логическую задачу (вариант №1)  

### Текст задачи  

Болельщики  футбольных  команд  делали  прогнозы  об  итогах  соревнований "Турнир четырех":  
— Я уверен, что Спартак будет чемпионом, а ЦСКА займет последнее место — сказал Иван.  
— Что  ты,  Спартак  выше  третьего  не  поднимется,  а  ЦСКА  станет  вторым  — возразил Сергей.  
— Чемпионом  будет  Динамо,  а  ЦСКА  войдет  в  тройку  сильнейших  —  сделал свой прогноз Петр.   
— Динамо  будет  вторым,  а  вот  Ротор  точно  будет  последним  —  промолвил Алексей.  
Выяснилось, что каждый из болельщиков был прав в одном прогнозе и ошибся во втором. Как распределились места, занятые командами?   

### Алгоритм решения  

**1: Инициализация и обработка ошибок**
1. Запускается предикат `main`.
2. `main` оборачивает вызов `solve_and_show` в конструкцию `catch/3`. Если во время работы программы произойдет ошибка, она будет перехвачена, и на экран выведется сообщение.
3. Вызывается `solve_and_show`.

**2: Генерация всех возможных вариантов (Перебор)**
1. В `solve_and_show` вызывается `all_rankings(All)`.
2. Предикат `all_rankings` определяет список команд: `Teams = [spartak, cska, dinamo, rotor]`.
3. С помощью `findall` собираются все возможные решения предиката `permutation_places(Teams, R)`.
4. **Реализация `permutation_places`:**
   * Берется список мест `[1, 2, 3, 4]`.
   * Генерируются все возможные перестановки этих мест (`permutation`). Всего существует (4!) 24 перестановки.
   * Каждая перестановка мест сопоставляется с командами с помощью `pair_teams_places`.
5. В результате `All` — это список из 24 возможных вариантов распределения мест.

**3: Фильтрация решений по условиям задачи**
1. `solve_and_show` перебирает все варианты из списка `All` с помощью `member(R, All)`.
2. Для каждого варианта `R` вызывается `valid_ranking(R)`, который проверяет истинность высказываний всех четырех болельщиков.
3. **Логика проверки (Исключающее ИЛИ):**
   * Каждый предикат проверяет два условия.
   * Если первое условие истинно, переменная `T1` становится `true`, иначе `false`.
   * Если второе условие истинно, переменная `T2` становится `true`, иначе `false`.
   * Проверка `T1 \= T2` гарантирует, что ровно **одно** из двух утверждений истинно, а второе ложно.
4. **Условия болельщиков:**
   * **Иван (`ivan_ok`):** `spartak` на 1-м месте ИЛИ `cska` на 4-м.
   * **Сергей (`sergey_ok`):** `spartak` на 3-м или выше (P >= 3) ИЛИ `cska` на 2-м.
   * **Петр (`petr_ok`):** `dinamo` на 1-м месте ИЛИ `cska` на 3-м или ниже (P =< 3).
   * **Алексей (`aleksey_ok`):** `dinamo` на 2-м месте ИЛИ `rotor` на 4-м.
5. Если `valid_ranking(R)` возвращает `true`, значит, этот вариант `R` является решением задачи.

**4: Вывод результата**
1. Как только найдено правильное решение, вызывается `show_result(R)`.
2. `show_result` сортирует список `R` по возрастанию мест.
3. Затем `show_places` рекурсивно выводит на экран каждую команду и занятое ею место в формате `Place ~w - ~w`.

**5: Завершение работы**
1. После вывода решения вызывается `wait_for_user`, который ждет нажатия любой клавиши (через `get_char(_)`).
2. Программа выводит `Program finished.` и завершается.
