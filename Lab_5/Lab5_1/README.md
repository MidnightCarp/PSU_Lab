# Вахрушева Влада ИТС Лабораторная №5  

# Задание 1  

Рекурсия (вариант №1)  

### Текст задачи  

Дано натуральное число N. Составить программу формирования списка, элементами которого являются цифры числа N.  

### Алгоритм решения  

**Шаг 1: Инициализация**
1. Запускается предикат `main`.
2. `main` вызывает предикат `loop_digits`.

**Шаг 2: Начало цикла**
1. Активируется предикат `repeat`, который создает точку возврата для организации бесконечного цикла.

**Шаг 3: Запрос ввода**
1. На экран выводится приглашение: `Enter a natural number N or q to exit: `.
2. Буфер вывода очищается (`flush_output`), чтобы текст появился сразу.
3. Считывается строка ввода от пользователя и сохраняется в переменную `S` (`read_line_to_string`).

**Шаг 4: Проверка на выход**
1. Проверяется, равна ли строка `S` символу `"q"` или `"Q"`.
2. **Если да (Пользователь хочет выйти):**
   * Выводится сообщение `Exiting program.`
   * Символ `!` (cut) отсекает точку возврата, созданную `repeat`. Цикл прерывается.
   * Программа завершается.
3. **Если нет:** Переход к Шагу 5.

**Шаг 5: Попытка преобразования в число**
1. Программа пытается преобразовать строку `S` в число `N` (`number_string`).
2. Проверяется, является ли `N` целым числом (`integer`) и больше или равно нулю (`N >= 0`).
3. **Если это натуральное число (Успех):**
   * Число `N` преобразуется в список ASCII-кодов его символов (`number_codes`).
   * С помощью `maplist` каждый код преобразуется в числовое значение цифры с помощью предиката `code_digit`.
   * На экран выводится полученный список цифр: `List of digits: [1, 2, 3]`.
4. **Если это не натуральное число (Ошибка):**
   * Выводится сообщение об ошибке: `Error: "[введенный текст]" is not a natural number.`

**Шаг 6: Возврат к началу**
1. Вызывается предикат `fail`. Это заставляет программу "откатиться" назад.
2. Так как `fail` всегда ложен, управление возвращается к ближайшей точке возврата — предикату `repeat`.
3. Цикл начинается заново (переход к Шагу 3).

---

### Описание вспомогательного предиката `code_digit`
Этот предикат используется для перевода ASCII-кода символа в его числовое значение.
* `Code` — это ASCII-код символа (например, для символа `'5'` это 53).
* `0'0` — это синтаксис Prolog для обозначения ASCII-кода символа `'0'` (это 48).
* `Digit is Code - 0'0` — вычитает 48 из кода. Например, `53 - 48 = 5`. Это позволяет получить реальное число `5` из символа `'5'`.
