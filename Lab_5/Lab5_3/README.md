# Задание 3  

Решить задачу на обработку списка (вариант №1)  

### Текст задачи  

Определим множество как список без повторяющихся элементов. Найти симметричную разность множеств.  

### Алгоритм решения  

**Шаг 1: Инициализация**
1. Запускается предикат `main`.
2. `main` вызывает `loop_symdiff`.

**Шаг 2: Запрос первого множества**
1. На экран выводится приглашение: `Enter the first set (list) or q to exit: `.
2. Считывается терм от пользователя с помощью `read(A)`.
   * *Важно:* `read` ожидает ввод с точкой на конце (например, `[1,2,3].` или `q.`).

**Шаг 3: Проверка на выход (для первого множества)**
1. Проверяется, равен ли введенный терм `A` атому `q`.
2. **Если да:** Выводится сообщение `Exit.`, и программа завершается (предикат `loop_symdiff` завершается успешно, так как нет рекурсивного вызова).
3. **Если нет:** Переход к Шагу 4.

**Шаг 4: Запрос второго множества**
1. На экран выводится приглашение: `Enter the second set or q to exit: `.
2. Считывается терм от пользователя с помощью `read(B)`.

**Шаг 5: Проверка на выход (для второго множества)**
1. Проверяется, равен ли `B` атому `'q'` или `'Q'`.
2. **Если да:** Выводится сообщение `Exit.`, и программа завершается.
3. **Если нет:** Переход к Шагу 6.

**Шаг 6: Вычисление симметрической разности**
1. Вызывается `difference(A, B, D1)`. Это находит все элементы, которые есть в `A`, но отсутствуют в `B` (разность $A \setminus B$).
2. Вызывается `difference(B, A, D2)`. Это находит все элементы, которые есть в `B`, но отсутствуют в `A` (разность $B \setminus A$).
3. Вызывается `append(D1, D2, SymDiff)`. Это объединяет два полученных списка в один — это и есть симметрическая разность.

**Шаг 7: Вывод результата**
1. На экран выводится результат: `Symmetric difference: ~w~n`.

**Шаг 8: Повтор цикла**
1. Вызывается `loop_symdiff` снова (рекурсивный вызов).
2. Программа возвращается к Шагу 2 (запрос первого множества).

---

**Реализация вспомогательного предиката `difference/3`**
Этот предикат реализует операцию разности множеств ($A \setminus B$). Он работает рекурсивно:

*   **Базовый случай:** `difference([], _, [])`. Если первый список пуст, результат тоже пуст.
*   **Случай 1 (Элемент не входит во второй список):** 
    ```prolog
    difference([H|T], B, [H|R]) :- \+ member(H, B), difference(T, B, R).
    ```
    Если голова первого списка (`H`) **не** принадлежит второму списку (`\+ member(H, B)`), то она включается в результат, и рекурсия продолжается для хвоста (`T`).
*   **Случай 2 (Элемент входит во второй список):**
    ```prolog
    difference([_|T], B, R) :- difference(T, B, R).
    ```
    Если голова первого списка **принадлежит** второму списку, она просто игнорируется (не попадает в результат), и рекурсия продолжается для хвоста.
