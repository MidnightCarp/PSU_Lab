# Задание 1  
List.map (на основе данного списка получить новый список) (вариант №1)  
### Текст задачи  
Получить список из первых цифр чисел, содержащихся в исходном списке  
### Алгоритм решения  
1. Реализация рекурсивной функции readList  
   A. Ввод числа с клавиатуры  
   B. Если строка пустая — вернуть пустой список (завершение ввода)  
   C. Если не пустая - проверка на Double   
   D. Если пройдена - добавляет число в начало списка и повторно вызывает функцию  
   E. Если не пройдена - выводит сообщение и повторно вызывает функцию  

2. Реализация функции firstDigit  
   A. Если число = 0, возращает 0  
   B. Иначе берет модуль числа, преобразовывает в строку, берет первый символ строки (Seq.head)  
   C. Обратное преобразование: символ в строку, строку в число  
   D. Возвращает полученную цифру  

3. Основная программа  
   A. Вызов readList, сохранение результата в oldList  
   B. Вывод исходного списка на экран в стандартном формате  
   C. Формирование нового списка: применить к oldList функцию List.map int (отбросить дробную часть, получив целые числа), применить к List.map firstDigit  
   D. Вывести полученный список newList на экран в стандартном формате  
   E. Завершение работы (вернуть 0)

# Задание 2  
List.fold (вариант №1)  
### Текст задачи  
Сколько раз в списке встречается заданное число?  
### Алгоритм решения  
1. Реализация рекурсивной функции readStringList  
   A. Ввод строки с клавиатуры  
   B. Если строка пустая — вернуть пустой список (завершение ввода)  
   C. Иначе: добавление строки в начало списка и повторный вызов функции  
 
2. Реализация рекурсивной функции readNumber  
   A. Ввод числа с клавиатуры  
   B. Проверка на double  
   C. Повторный вызов функции, если проверка не пройдена  

3. Реализация функции countOccurrences для подсчёта вхождений  
   A. Принимает два параметра: искомую строку (target) и список строк (items)  
   B. Проходится по списку с помощью List.fold, накапливая счётчик: если элемент списка = target, счетчик увеличивается на 1  
   C. Возвращает итоговое значение счетчика  

4. Основная программа  
   A. Вызов readStringList для получения списка, сохранение результата в items  
   B. Вызов readNumber для получения искомого числа, сохранение результата в comparisonValue  
   C. Преобразование числа в строку для сравнения с элементами списка  
   D. Вывод исходного списока на экран в стандартном формате  
   E. Вызов countOccurrences, вывод полученного результата на экран  
   F. Завершение работы (вернуть 0)
